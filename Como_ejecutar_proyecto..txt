¿Como puedo ejecutarlo el proyecto verlo?


El proyecto tiene dos partes separadas, por lo que necesitas abrir dos terminales 
diferentes.

Terminal 1: Navegas a cd backend y ejecutas el comando python backend.py
Terminal 2: Navegas a cd FrontEnd y ejecutas el comando npm start

Puedes abrir tu navegador e ingresar directamente para ver tu página:
http://localhost:4200
